# Unity Shooter

A simple 3D shooter game built with Unity.

## Features

- Camera follow system (`CameraFollow`)
- Unity-based 3D shooter gameplay

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Eperche/My-PRECIOUS.git
   ```

2. Open Unity Hub.
3. Click **Add** and select the `gameProject` folder.
4. Open the project in Unity.
5. Select your target platform under **File → Build Settings** and build the project.

## Project Structure

```text
gameProject/
├── Assets/
│   └── Scripts/       # C# scripts
└── ProjectSettings/   # Unity project settings
```

## Requirements

- Unity Editor (compatible version)
- Unity Hub
